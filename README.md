# O que é o BlackBird? 🐦‍⬛

BlackBird é um protótipo de aplicativo que simula um ambiente virtual de aprendizagem. Foi criado com o objetivo de permitir que provas de conceito voltadas para tecnologias e Frameworks Apple fossem realizadas, de forma que se encaixassem a contextos reais do cotidiano.

## App Clip

Tecnologia aplicada a fim de permitir que o usuário acesse uma funcionalidade específica do aplicativo sem a necessidade de baixá-lo. Ao escanear algum mecanismo que possua a URL de invocação, como um **QRCode** ou **App Clip Code**, ocorre um direcionamento automático para o Card do App Clip e, em seguida, para uma view isolada do aplicativo que possua a função desejada.

No Blackbird, redireciona para a tela de notas do aluno, o permitido ter acesso facilitado à informações importantes que normalmente requereriam muitos passos para alcançar. 

## WidgetKit

Framework utilizado para a construção de Widgets, extensões de um aplicativo que permitem visualizar rapidamente informações importantes e acessar funcionalidades específicas sem precisar abrir o app. Em sua maioria, estão localizados na tela inicial do dispositivo, com interfaces personalizadas e diferentes tamanhos passíveis de serem escolhidos pelo usuário.

Sua aplicação no Blackbird se dá pela tela "Cronograma", permitindo que o usuário visualize seu cronograma diário de aulas de forma simples e dinâmica.
